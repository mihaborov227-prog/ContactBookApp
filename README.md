# Contact Book App

**Автор:** Иван Иванов (замените на свои ФИО)

Графическое приложение для управления списком контактов с сохранением в JSON, фильтрацией и валидацией ввода.

## Возможности
- Добавление контакта (имя, телефон, email) – имя и телефон обязательны.
- Валидация: телефон только из цифр, символов `+ - ( )`; email должен содержать `@`.
- Удаление выбранного контакта.
- Фильтрация списка по имени (регистронезависимый поиск).
- Автоматическая загрузка и сохранение в `contacts.json`.
- Генерация уникального ID для каждого контакта с помощью `random`.
